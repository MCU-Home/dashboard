# Development install:
#
#     python3 -m venv .venv && . .venv/bin/activate
#     pip install -r requirements-dev.txt
#
# `mcuhome-workbench` (with `mcuhome-model` under it) is imported
# in-process (ADR 0011) but is not published yet, so it is installed
# from the sibling checkout of the west workspace. The bare `mcuhome` is
# the command line's distribution and is deliberately not installed:
#
#     <workspace>/mcuhome/            the builder (this line)
#     <workspace>/dashboard/backend/  this package
#
# Point the path elsewhere if your checkout is laid out differently. The
# supported version range is asserted at startup from
# mcuhome_dashboard/versions.py, not from this file.
-e ../../mcuhome/packaging/model
-e ../../mcuhome/packaging/workbench
# The dashboard never compiles (ADR 0019); workbench pulls model and is
# the whole runtime surface. The compiler is deliberately NOT installed,
# which keeps ADR 0017 §2 checkable in this very venv.

-e .[dev]
