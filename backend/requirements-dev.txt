# `mcuhome-workbench` is imported in-process (ADR 0011) but is not
# published yet, so it is installed from the sibling checkouts — since
# the ADR 0024 repo split it lives at the root of the mcuhome
# repository, and `mcuhome-model` comes from the mcuhome-sdk repository:
#
#     <workspace>/mcuhome-sdk/        the SDK (model + compiler)
#     <workspace>/mcuhome/            the workbench
#     <workspace>/dashboard/backend/  this package
#
# Point the paths elsewhere if your checkout is laid out differently. The
# supported version range is asserted at startup from
# mcuhome_dashboard/versions.py, not from this file.
-e ../../mcuhome-sdk/packaging/model
-e ../../mcuhome
# The dashboard never compiles (ADR 0019); workbench pulls model and is
# the whole runtime surface. The compiler is deliberately NOT installed,
# which keeps ADR 0017 §2 checkable in this very venv.
