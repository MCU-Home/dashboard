# What goes into the published images, as opposed to what a developer
# installs (backend/requirements-dev.txt, sibling checkouts in a west
# workspace).
#
# Neither the workbench nor the model is on PyPI yet, so both come from
# git, pinned to a commit rather than to a branch: an image is a release
# artifact and must build the same way twice. Bump these when cutting a
# dashboard release, in the same commit that moves the version.
#
# The `remote` extra and no other. It brings the session client's HTTP
# stack and zstd codec, which is what the App can actually use: building
# on a build server. `local` is deliberately absent — it resolves to
# `mcuhome-compiler`, and the dashboard never compiles. Installing the
# command line here would pull that extra in through the back door
# (`mcuhome` depends on `mcuhome-workbench[local,remote]`), which is why
# these images do not ship it.
